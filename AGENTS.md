# Relife Clinic OS — Agent Instructions

## Owner communication language (mandatory)

For every AI assistant, coding agent, reviewer, or automation working in this repository:

- Communicate directly with the project owner in **Bengali (Bangla)**.
- Questions, explanations, decisions, approval requests, warnings, status updates, and next-step instructions for the owner must be in Bangla.
- English is allowed when it is the actual copy-paste payload for another AI/agent/tool, or when required for code, commands, identifiers, logs, APIs, or other technical artifacts.
- If you provide an English prompt/message for Claude, ChatGPT, Codex, Copilot, or another agent, explain in Bangla what that English text is for and what the owner should do with it.
- Never require the owner to interpret an English technical message without a Bangla explanation.
- If clarification or approval is needed from the owner, ask for it in Bangla.
- This rule applies even when the source material or another agent's message is in English, unless the owner explicitly requests a different language for that specific response.

Treat this as a repository-wide communication requirement, not a preference limited to one assistant or one chat session.
